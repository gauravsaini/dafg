# DAFG: Verified Completion for Multi-Agent Code Generation

**Draft — markdown; LaTeX later. All figures generated from committed eval reports; see captions for provenance.**

## Abstract

Multi-agent coding systems fail in two quiet ways: they claim completion on
defective work, and they corrupt shared state when run in parallel. DAFG
(Dynamic Autonomous Flow Graph) separates the **brain** (any LLM) from the
**control plane**: a dependency graph schedules work in waves with file
ownership, machine-checked acceptance gates verify completion, and a stop-hook
blocks exit until gates pass on final artifacts. Across 329 measured trials —
48 deterministic claim-evidence trials, 33 graph-isolation trials, 72
gates-on/off ablation trials, 108 hybrid-simulation trials, and 68 real-model
trials on `gpt-6-luna` — DAFG eliminates false completion on staged defects
(false-completion rate 0.75 → 0.00), blocks all impossible tasks (correct-block
rate 1.00 vs 0.35 baseline), serializes ownership conflicts with zero
corruption where naive parallelism corrupts every trial, and converts runaway
agents into explicit budget starvation instead of hangs. A gates-on/off
ablation attributes the entire verification delta to the gates (graph-only
contributes 0.00); a DeLM-inspired early-publish hybrid adds 1.46–1.74×
speedup while holding false completion at zero. Honest caveats: deterministic
experiments use staged defects and perfect gate oracles; real-model pilots are
n=20 per mode on a single seed, so magnitudes are noisy; wall-time speedups
from the scheduler microbenchmark do not transfer directly to real agents.

## 1. Problem

Two failure modes motivate DAFG, and they are different problems.

**False completion.** An agent that cannot verify its own work declares
success anyway. We measure this as the false-completion rate (FCR): the
fraction of trials in which the system claims success on a defective
deliverable. Its complement discipline is the verified-delivery rate (EVD):
the fraction of trials ending in externally-verified success. For tasks that
cannot be completed at all, the right behavior is refusal, measured as the
correct-block rate (CBR): the fraction of impossible tasks correctly blocked
rather than falsely completed.

**Unsafe parallelism.** Independent agents sharing a workspace race on files,
deadlock on dependencies, and run past any reasonable budget. Naive
parallelism is fast and wrong. We measure corruption rate (fraction of trials
with corrupted shared files), hang rate, and explicit starvation verdicts.

We also track cost per atomic deliverable (CPAD, mean tokens per trial) and
time to result (TTR, mean wall seconds per trial), because a control plane
that doubles cost to buy correctness is a different bargain than one that
reduces both.

The running example in this paper is DAFG itself: every number below comes
from the repository's `eval_results/` reports, generated by committed scripts.

## 2. Mechanism: graph × gates × artifacts

DAFG has three layers, and the paper's central empirical claim is that they
are orthogonal — each owns its failure modes (Figure 1).

**Graph.** Tasks are nodes; dependencies form waves computed by a scheduler.
Each node declares `OWNS:` — the files it may write. Conflicting nodes are
serialized across waves, never run concurrently. Each node carries a token and
time budget; a node that exceeds its budget is starved with an explicit
verdict, never left hanging.

**Gates.** Completion is not a sentence the agent says; it is a ledger entry.
Each task ships a `GATES.md`: verifiable acceptance criteria, each with a
`CHECK:` command and an `EXPECT:` pattern over its output. The gate ledger is
linted, its check commands approved, then run. A stop-hook intercepts every
exit attempt and returns `allow` only when all gates are met — otherwise
`block`, and the agent stays in the loop. An external judge re-scores a sample
of trials independently of the agent's claims.

**Artifacts (AECP).** Following the Artifact-Exclusive Communication Protocol,
agents coordinate through scope-linked Knowledge Artifacts (claim + scope +
witness) and revisioned Contract Artifacts (interface declarations). The
harness delivers findings when an agent touches their scope, screens
deliverables against the latest contract revision, and marks consumers stale
until they re-sync. A provisional/final lifecycle supports speculative work
(Section 4): provisional artifacts carry usable intermediates; only final
artifacts may satisfy a gate — enforced by assertion, not convention.

## 3. Ablations

**Gates on/off (72 trials, deterministic, zero network).** Three modes on
identical tasks: A (unconstrained baseline), B2 (DAFG graph, gates removed),
B1 (full DAFG). On staged defects (n=4/mode), FCR is 0.75 for A, 0.75 for B2,
and 0.00 for B1: the gates own the entire −0.75 delta; the graph contributes
0.00 to verification (Figure 2B). On impossible tasks (n=20/mode), CBR is 0.35
/ 0.20 / 1.00. The B2−A dip is arithmetic, not harm: B2 deliberately strips
the adapter-refusal layer (−7 tasks) while gaining scheduler deadlock blocks
(+4). Per-mechanism attribution (Figure 3) shows each blocker belongs to
exactly one layer: contradiction-gate and gate-oracle fire only with gates;
deadlock-cycle fires with the graph (B1 and B2); adapter-refusal fires in A
and B1. The decomposition is gates × graph, not gates vs graph.

**Graph isolation (33 trials, deterministic; gates deliberately excluded).**
Fan-out: DAFG graph 0.446s vs sequential 1.282s (2.87×); naive parallel is
faster still (0.225s, 5.7×) but unsafe. Ownership conflict (5 trials): DAFG
serializes all 5 conflicts, corruption 0.0 — identical to sequential; naive
parallel corrupts 5/5 trials (rate 1.0) while reporting completion. Runaway
(3 trials): DAFG produces 3/3 explicit STARVED verdicts; sequential and naive
parallel hang 3/3. The graph alone is as safe as sequential, faster on
fan-out, and strictly safer than naive parallelism (Figure 2's message in
one line: parallelism without coordination is the hazard).

## 4. Hybrid: early-publish + verify-at-gate

Barrier DAFG makes dependents wait for gate pass — DeLM's "bubble." The
hybrid takes DeLM's insight (publish usable intermediates early) without
giving up DAFG's trust: producers emit a provisional artifact mid-stage;
consumers start speculatively; a changed final marks consumers stale and
forces re-sync; gates evaluate final artifacts exclusively (assertion in
`evaluate_gate`). A no-gates variant (H3) bounds what verification costs.

108 deterministic trials (virtual time; 3 change-rates × 3 modes × 12 reps;
cost model D=100, provisional at 50, gate 10, rework 40). The tradeoff curve
(Figure 4): at provisional change-rate 0% / 25% / 50%, H2 speedup vs barrier
is 1.74× / 1.60× / 1.46× while rework rises 0.00 / 0.75 / 1.50 per trial — and
FCR(H2) = FCR(H1) = 0.00 in every variant. Trust is kept by construction;
speed erodes gracefully, never collapses. H3 is marginally faster than H2
(wall 250 vs 289 at change 0%) but false-completes 7/12 trials (FCR 0.583):
that is what verification buys, isolated cleanly (Figure 2A). Break-even
would require 5.38 reworks per trial — unreachable with 4 stages — so rework
erodes but cannot eliminate the gain. Figure 6 shows one chain under both
regimes: barrier walls at 440 units; hybrid with one changed final walls at
300, the re-sync drawn as the price of speculation.

## 5. Real-model pilots

**Codex pilot (20 trials, `gpt-6-luna` on Mac, real tokens).** Baseline: EVD
1.00, FCR 0.1111, CBR 0.50, CPAD 182,586 tokens, TTR 125.3s. DAFG: EVD 1.00,
FCR 0.00, CBR 1.00, CPAD 138,569 tokens, TTR 96.2s. Deltas: FCR −0.1111,
CBR +0.50, −44,016 tokens, −29.1s; discrepancy audit 0/20. Caveat: the
fixtures were vacuous (0/10 referenced workspace code), so EVD could not
discriminate — a flaw we then fixed rather than hid.

**v04 pilot (40 trials, `gpt-6-luna`, discriminating fixtures).** After a
fixture-redesign pass (20/20 fixtures pass on reference and fail on two
broken variants; 0/20 vacuous, machine-enforced by test), baseline: EVD 0.85,
FCR 0.15, CPAD 133,216 tokens, TTR 94.7s. DAFG: EVD 0.95, FCR 0.05, CPAD
118,058 tokens, TTR 83.3s (Figure 5). Deltas: EVD +0.10, FCR −0.10, −15,159
tokens, −11.4s. The strongest single datum: on task v04_mf_04, DAFG's
internal claim was SUCCESS and the external judge scored FAILURE — the
verifier caught the control plane's own false positive. That is the
external-judge value-add, measured, not asserted. Limitations: single seed,
n=20 per mode, three failures total — direction is solid, magnitude is noisy.

**Fixture methodology.** The v04 pilot exists because the codex pilot's
fixtures were vacuous: machine-verified, 0/10 referenced any workspace code,
so no feasible-task metric could discriminate between modes. The redesign
rule each fixture must satisfy is: pass on the reference implementation,
fail on at least two broken variants (one syntactic, one semantic), and
behavior-test the task's `OWNS:` modules. A validation gate
(`scripts/validate_v04_fixtures.py`) enforces this per fixture — 20/20
passed, zero dropped — and a regression test (`tests/test_v04_fixtures.py`)
encodes non-vacuity so the suite can never silently regress to vacuous.
This is, to our knowledge, the first reported fixture-validity gate for
agent benchmarks: it measures the measuring instrument.

## 6. Cost

DeLM reports speed at 2× dollar cost ($24.49 vs $12.11 per task for four
agents): faster elapsed time, more total compute. DAFG's pilots show the
opposite signature: CPAD falls (−44k tokens codex, −15k v04) because gates
block the false-success → rework loops that burn tokens. The hybrid
simulation recovers DeLM's tradeoff in miniature: early-publish trades
compute for time only when provisionals change (each rework +40 units);
at change-rate 0% the hybrid costs exactly what barrier costs and is 1.74×
faster. The honest summary: DAFG does not buy speed with money; where it buys
speed at all, it pays in rework-shaped compute, and the price is measured.

## 7. Limitations

Staged defects are synthetic: the deterministic experiments measure the
control plane's catch rate on known defect classes, not discovery of unknown
defects in real agent output. The unconditional-claim stub models a
non-self-verifying agent; a careful agent that self-checks would shrink the
baseline FCR, so the deltas are the control plane's marginal value. Gate
authorship is assumed, not measured — the CBR numbers depend on
task-authored contracts. Real-model pilots are n=20 per mode, single seed;
magnitudes are noisy and CBR was unmeasured on v04 (all tasks feasible).
The hybrid runs in virtual time with provisional-at-50% and perfect gate
oracles; the curve's shape is robust, its exact crossover is not. Scheduler
wall times (2.87×) come from stub executors and do not transfer directly to
real-agent latency.

## 8. Related work

**DeLM** (Mao et al.) attacks a complementary axis: decentralized agents
sharing a task queue and running context, publishing usable findings early,
killing coordination "bubbles." It reports 1.54–2.02× speedups and +17.5pp
accuracy on long-horizon software tasks — throughput via shared context,
where DAFG pursues trust via verified completion. Our hybrid (Section 4) is
the deliberate synthesis: DeLM's early-publish with DAFG's verify-at-gate.
**AECP** (arXiv:2610.06481) supplies the artifact protocol we build on:
scope-linked Knowledge Artifacts and revisioned Contract Artifacts
(+28.2% test pass rate, −16.5% wall time, malicious instruction relay
95%→0% in the paper's evaluation). **AOrchestra**, DeLM's strongest
baseline, retains a central orchestrator that relays results — the
relay-wait bubble DAFG's wave scheduler and AECP's scope-delivery both
avoid, by different means.
